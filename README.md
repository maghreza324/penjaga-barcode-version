# penjaga-barcode-version

Repo kecil buat nyimpen file `version.json` yang dicek otomatis sama aplikasi Penjaga Barcode buat notifikasi update.

Cara update versi:
1. Edit `version.json`, naikkan field `version` sesuai versi baru.
2. Ganti `url` kalau perlu, arahkan ke halaman download versi terbaru.
3. Commit & push ke branch `main`.
